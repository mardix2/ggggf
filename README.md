# Arcanum Mysticum

Обширный мод на магию для **Minecraft 1.21.11**, загрузчик **Fabric**.

Мана вместо «ещё одного меча», семь школ, 43 заклинания, четыре ступени посохов,
мантия чародея, своя руда, алтарь превращения и книга заклинаний с интерфейсом.

---

## ⚠️ Прочитайте это первым

Мод написан целиком, со всеми ресурсами, но **не собирался** в среде, где его
писали: там закрыт доступ к `maven.fabricmc.net` и серверам Mojang, без которых
Fabric Loom не может скачать ни маппинги, ни сам Minecraft. Поэтому:

* весь JSON, все текстуры, переводы, рецепты, модели и таблицы добычи
  проверены офлайн-валидатором (`python3 tools/validate.py` — 243 файла, все проверки проходят);
* Java-исходники проверены `javac` на синтаксис — структурных ошибок нет;
* **но компиляция против настоящего API Minecraft 1.21.11 ещё не выполнялась.**

Ниже, в разделе [«Что проверить при первой сборке»](#что-проверить-при-первой-сборке),
перечислены конкретные места, где API Minecraft/Fabric менялся между версиями.
Их специально собрали в отдельные небольшие файлы, чтобы правка занимала одну строку.

## Сборка

```bash
# 1. Сверьте четыре версии в gradle.properties (см. ниже)
# 2. Соберите
./gradlew build
# готовый jar: build/libs/arcanum-1.0.0.jar

# запуск клиента для проверки
./gradlew runClient
```

Нужна **Java 21**.

## Как играть

### С чего начать

1. **Найдите аркановую руду.** Она встречается в камне и глубинном сланце
   примерно на тех же глубинах, что и железо, и чуть чаще — ниже −8.
2. **Сделайте жезл ученика** (2 палки + аркановый кристалл) — он уже умеет
   колдовать, но только заклинания первой ступени.
3. **Соберите алтарь превращения.** Это главный «верстак» мода.
4. **Запишите первый свиток** на алтаре — свиток и есть способ выучить заклинание.

### Алтарь превращения

Алтарь работает не через интерфейс, а через обряд:

1. Поставьте алтарь.
2. **Выбросьте ингредиенты на землю** рядом с ним (клавишей выброса, по умолчанию `Q`),
   в радиусе 3 блоков.
3. Щёлкните по алтарю правой кнопкой.
4. Три секунды предметы кружат над алтарём — и превращаются в результат.

Если обряд прервать (например, забрать ингредиенты), **ничего не пропадёт**:
предметы всё это время лежат на земле, а потраченная мана возвращается.

Рецепты высоких ступеней требуют **аркановых постаментов** вокруг алтаря
(до 6 штук) и списывают ману с того, кто запустил обряд.

### Свитки

Свиток — единственный способ выучить заклинание в выживании.

* **ПКМ** — разовое применение за половину стоимости, без требований к посоху.
* **Присед + ПКМ** — выучить заклинание навсегда (свиток расходуется).

Свитки записываются на алтаре: `чистый свиток + руна школы + напитанный кристалл`.
Алтарь выберет случайное заклинание этой школы, **отдавая предпочтение тем,
которых вы ещё не знаете**.

### Управление

| Действие | По умолчанию |
|---|---|
| Открыть книгу заклинаний | `R` |
| Следующее заклинание | `X` |
| Предыдущее заклинание | `Z` |
| Применить заклинание | ПКМ с посохом в руке |
| Переключить заклинание без книги | присед + ПКМ с книгой заклинаний |

Полоса маны и выбранное заклинание — в левом верхнем углу.

### Команды

| Команда | Кому | Что делает |
|---|---|---|
| `/arcanum spells` | всем | справочник по всем заклинаниям |
| `/arcanum known` | всем | что вы уже знаете |
| `/arcanum dispel` | всем | развеять своих призванных |
| `/arcanum mana fill` | оператору | наполнить ману |
| `/arcanum mana set <n>` | оператору | выставить ману |
| `/arcanum attunement <0-12>` | оператору | выставить число печатей разума |

| `/arcanum learn <id>` | оператору | выучить одно |
| `/arcanum forget all` \| `<id>` | оператору | забыть |

## Мана

| Что | Сколько |
|---|---|
| База | 100 |
| Печать разума (до 12 штук) | +25 каждая |
| Мантия чародея, полный комплект | +110 |
| Посохи | от +0 (жезл) до +120 (скипетр) |
| Восстановление | 0.25/тик = 5 в секунду |
| Рядом с Источником маны | ×4 |

Максимум при полной раскачке — около **630**.

Снаряжение перемножает стоимость заклинаний, а не складывает скидки, —
иначе полный комплект уводил бы цену в ноль.

### Мантия чародея

Защита чуть выше кожаной, зато комплект даёт **+110 к максимуму маны**,
**+4.4 маны в секунду** и **−13 % к стоимости** заклинаний.
Чинится напитанным кристаллом.

### Фокусы

Носятся во второй руке. Дают **+30 % к силе своей школы** и −5 % к стоимости
любых заклинаний.

## Что проверить при первой сборке

Эти места зависят от версии API. Если сборка где-то споткнётся — почти
наверняка здесь, и правка будет однострочной.

| Файл | Что в нём версионно-зависимого |
|---|---|
| `client/ArcanumKeys.java` | `KeyBinding.Category` — появился в 1.21.6. Для более ранних версий категория задаётся строкой `"key.categories.arcanum"`. |
| `client/ArcanumHud.java` | `HudElementRegistry` (Fabric 1.21.6+). До этого — `HudRenderCallback`. Регистрация вынесена в отдельный метод `register()`. |
| `client/ArcanumClient.java` | `BlockRenderLayerMap` — в моделях блоков продублировано полем `render_type`, так что даже без него прозрачность отработает. |
| `spell/util/Fx.java` | Все вызовы частиц. `DustParticleEffect(int, float)` — формат 1.21.5+; `World#addParticleClient` — переименование 1.21.5. |
| `registry/ModArmorMaterials.java` | `ArmorMaterial` как record + `EquipmentAsset` — формат 1.21.5+. |
| `block/*.java` | `ShapeContext` (`net.minecraft.block.ShapeContext`) и сигнатура `onUse`. |
| `entity/SpellProjectileEntity.java` | `ThrownItemEntity` в пакете `entity.projectile.thrown` (1.21.2+), `getGravity()`. |

Чего в моде **нет** намеренно — ради устойчивости к смене версий:

* ни одного миксина;
* ни одного своего рендерера сущностей или блок-сущностей;
* ни одного `ScreenHandler` и ни одной текстуры интерфейса
  (книга заклинаний нарисована примитивами);
* ни одного своего типа урона (используются ванильные источники);
* ни одного своего звука (используются ванильные).

### Пересборка ресурсов

Все текстуры и JSON — производные файлы, они лежат в репозитории для удобства,
но пересобираются одной командой:

```bash
python3 tools/gen_textures.py   # текстуры
python3 tools/gen_assets.py     # модели, blockstate, переводы
python3 tools/gen_data.py       # рецепты, добыча, теги, генерация мира
python3 tools/validate.py       # проверка, что всё сходится
```

`validate.py` сверяет Java-код с ресурсами: если добавить заклинание в код и
забыть перевод — проверка это поймает.

### Добавить своё заклинание

1. Опишите эффект в нужном файле `spell/impl/*Spells.java`:

```java
Spell.builder("my_spell", SpellSchool.FIRE)
        .type(SpellCastType.PROJECTILE)
        .tier(2).cost(20.0f).cooldown(40)
        .action(ctx -> {
            SpellUtil.shoot(ctx, ModItems.RUNES.get(SpellSchool.FIRE), SpellSchool.FIRE,
                    ParticleTypes.FLAME, 1.6f, 0.02f, 0.0f,
                    (world, projectile, pos, hit) -> {
                        if (hit != null) {
                            SpellUtil.fireDamage(ctx, hit, ctx.scaled(6.0f), 60);
                        }
                    });
            return true;
        })
        .register();
```

2. Добавьте название и описание в `tools/content.py`.
3. `python3 tools/gen_assets.py && python3 tools/validate.py`.

Свиток для нового заклинания появится сам: алтарь выбирает случайное
заклинание школы, а не фиксированный список.

### Добавить свой обряд

Положите файл в `src/main/resources/data/arcanum/infusion/`:

```json
{
  "inputs": [
    { "item": "arcanum:infused_crystal", "count": 2 },
    { "item": "minecraft:diamond", "count": 1 }
  ],
  "result": { "item": "arcanum:mana_gem", "count": 1 },
  "pedestals": 4,
  "mana": 350
}
```

Обряды читаются как обычные ресурсы, так что их может добавлять и датапак.
Поле `scroll_school` превращает результат в свиток случайного заклинания школы.

## Совместимость

* Fabric API — обязателен.
* Мод не трогает ванильные классы (миксинов нет), поэтому конфликты с другими
  модами маловероятны.
* Данные игрока (мана, изученные заклинания, якорь) хранятся в attachment-ах
  Fabric и переживают смерть игрока.
* Блоки и предметы добавляются обычной регистрацией — мод безопасно удалить
  из мира, потеряв только свои блоки.
